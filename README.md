# Valheim Codex

A complete reference for Valheim: every item, creature, crafting station and building piece, with recipes, drop rates, star scaling, weak spots and prefab names, all linked together. Each biome has its own page, and a progression filter hides spoilers from places you haven't reached yet.

Live site: https://modestypooh.github.io/valheim-codex/
